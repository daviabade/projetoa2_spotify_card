# Spotify Card Personalizado!!!

Uma aplicação web interativa que permite aos usuários criar cards musicais personalizados inspirados no design premium do Spotify. Este projeto foi desenvolvido com foco em UI/UX e manipulação avançada do DOM para a disciplina de Análise e Desenvolvimento de Sistemas.

## Funcionalidades

*   **Pré-visualização em Tempo Real (Reatividade):** O card é atualizado instantaneamente no exato milissegundo em que o usuário digita os dados, utilizando eventos de `input`.
*   **Upload Local de Imagens:** Implementação da `FileReader API` do JavaScript para processar e exibir fotos da máquina do usuário instantaneamente, sem a necessidade de um servidor back-end.
*   **Temas Dinâmicos (Vibes):** A cor de fundo da página altera-se suavemente de acordo com a "vibe" da música escolhida, utilizando estruturas de decisão em JS.
*   **Design 100% Responsivo:** Interface fluida que se adapta perfeitamente a computadores, tablets e celulares, construída inteiramente com CSS Flexbox.
*   **Tipografia Customizada:** Integração da família tipográfica Avenir Next via `@font-face` local para garantir fidelidade absoluta ao protótipo do Figma.

## Tecnologias Utilizadas

*   **HTML5:** Semântica estrutural limpa e organizada.
*   **CSS3:** Variáveis globais, Flexbox, Media Queries, animações suaves e efeitos visuais como *Glow* (iluminação difusa por código).
*   **JavaScript (Vanilla):** Tratamento de eventos (`input`, `change`, `submit`) e manipulação direta do DOM sem uso de frameworks.
